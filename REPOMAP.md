## scripts/

- **check-rls.ts** — Fails if the database's row-level security posture has drifted. Run against any environment: `SUPABASE_DB_URL=... pnpm check:rls`. This is the test that stops "we'll add RLS later" from ever happening.
- **check-service-role-leak.ts** — Fails if the service-role key (or anything that would carry it) can reach the browser. Two layers: a source scan that always runs, and a bundle scan that greps the built client chunks for the literal key.
- **gen-types.ts** — Regenerates src/types/database.ts from the live dev database. Run after every migration; the output is committed so no agent ever has to read a migration to learn a column name. — exports: `Database`
- **generate-graph.ts** — Builds the module dependency graph with madge, fails on any circular dependency, and writes a text summary into the graph section of REPOMAP.md.
- **generate-repomap.ts** — Generates REPOMAP.md: one line per source file with its purpose (taken from the docblock at the top of the file) and its exported symbols. An agent reads this instead of globbing the repo and opening files.
- **madge.d.ts** — Minimal types for madge, which ships none. Only the surface scripts/generate-graph.ts actually uses is declared. — exports: `MadgeConfig`, `MadgeInstance`, `madge`
- **new-resource.ts** — Scaffolds a complete owned resource from templates: migration with RLS policies, Zod schemas, query helpers, API routes, server actions and a protected page. Deterministic — no model has to write any of it. pnpm new:resource task       (singular; the table becomes "tasks")
- **scan-secrets.ts** — Local push protection. GitHub's secret scanning is not available on a free private repo, so this hook is what actually stops a key reaching the remote. Wired up by `pnpm prepare` (git core.hooksPath) and run by .githooks/pre-push.
- **seed.ts** — Seeds one admin and two normal users, each with notes, so cross-user isolation can be checked by hand in ten seconds. Refuses to run against anything that looks like production.
- **verify.ts** — The one command. Runs every gate in cheapest-first order and stops at the first failure, printing that step's output and where to go to fix it.

- **20260909204930_init_security_baseline.sql** — Security baseline for the public schema and the private helper schema. Runs first so every later migration inherits a deny-by-default posture.
- **20260909204947_profiles.sql** — profiles: one row per auth.users row, created by a trigger on signup. Holds display name, avatar path and role. Role escalation is blocked twice: once by column-level grants, once by a BEFORE UPDATE trigger.

- **20260909205018_storage_avatars.sql** — Private avatars bucket. Objects are keyed <user_id>/<filename>, so the first path segment is the ownership check. Reads happen through short-lived signed URLs minted server-side; the bucket is never public.
- **20260910110828_profiles_role_guard_allows_privileged_roles.sql** — The role guard was blocking server-side seeding and administration. private.is_admin() reads auth.uid(), which is null for the service role, so every service-role write to profiles.role was rejected. `pnpm seed` failed on its first admin.  Privileged database roles are now trusted. They are reachable only from server code holding the secret key, or from a migration. The guard exists to stop the `authenticated` role, which is what a browser holds, and that path is unchanged.

## tests/

- **csp.test.ts** — The CSP is one string. A missing directive is a silent hole, so assert them.
- **rate-limit.test.ts** — The limiter is what a red team hits first. It must count, and it must expire.
- **safe-redirect.test.ts** — safeRedirect is the only thing stopping an open redirect off the login page.
